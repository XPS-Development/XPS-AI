# Ag/HOPG: исходная структура спектров с добавленными разложениями

Открывайте `ag-hopg-with-decompositions.json.gz`: это исходные два VAMAS в
структуре файл → исходная группа → исходный отдельный спектр, без готовых серий.
Ag3d hv20 и C1s hv20 остаются разными спектрами. Имена и группы не изменены,
все 228 спектров сохранены, включая O1s, survey и прочие линии.

Разложения добавлены к 136 отдельным спектрам из трёх серий ноутбука:
42 Ag + 42 C (Sample 2 after atm), 13 Ag + 13 C (New HOPG after atm),
13 Ag + 13 C (New HOPG after 240 mbar). Остальные спектры оставлены без разложений.
Готовых серий постобработки в документе нет: их нужно создать самостоятельно.
При подготовке проверены шесть отдельных серий Ag3d/C1s, результаты проверки
сохранены в provenance.json.

## Пройти самостоятельно

1. File → Open → `ag-hopg-with-decompositions.json.gz`.
2. Раскройте Sample 2 after atm.vms → After atm part 1. Откройте
   `1-Ag3d-hv20`: в нём два пика. Отдельно откройте `2-C1s-hv20`: три пика.
   Исходное написание групп с пробелами сохранено.
3. Post-processing → New под списком **Spectrum series**. Выберите семь Ag3d hv20
   из этой группы (без C1s/O1s), проверьте порядок измерения: 1, 4, 7, 10, 13,
   16, 19. Дерево сортирует имена как строки; исправьте порядок кнопками или
   перетаскиванием. Назовите серию Ag3d hv20.
4. Нажмите **Match peaks**, выберите тренд около 368 эВ. Проверьте его состав
   в **Trend components**, предварительный график в **Trend preview** и связи
   в **Neighbouring links**. Здесь можно назначить/разорвать связь с undo/redo.
   Назовите тренд **Ag3d 5/2** через **Name trend**.
5. **Add trend to table… → New analytical table…**, имя «Ag / C». Таблица
   появится в отдельном списке **Analytical tables**. Её можно оставить и
   вернуться к работе с сериями, не теряя состояния.
6. Аналогично создайте C1s-серию из 2, 5, 8, 11, 14, 17, 20 (основной пик
   около 284,58 эВ). Проверьте и назовите основной тренд C1s-A; добавьте его
   в существующую таблицу «Ag / C». При необходимости выберите второй
   C-тренд, назовите C1s-B и добавьте в ту же таблицу.
7. Откройте таблицу слева. **Sources…** позволяет проверить или изменить набор
   конкретных трендов с указанием серии и состава. Соответствие строится по
   порядку шагов; при разных длинах/покрытии показано предупреждение с числами.
   Число строк соответствует самой длинной серии, пропуски не сдвигают пары.
8. **Add column… → Position A - position B**: A=Ag3d 5/2, B=C1s-A. Отдельно
   добавьте **Area A / area B**. Для суммарного C выберите **Sum of selected
   areas** (C1s-A и C1s-B), затем **Sum of numerator areas / sum of denominator
   areas**: числитель Ag3d 5/2, знаменатель C1s-A и C1s-B. При пропуске любого
   C-компонента сумма и отношение остаются пустыми с причиной.
9. Сдвиг энергии задавайте относительно явно выбранной **Reference row**.
   Разные единицы на вкладке **Graphs** находятся в отдельных панелях; выбор
   столбцов сохраняется. Двойной щелчок по исходному значению открывает спектр
   и выделяет компонент. Для составного расчёта выбирается один из источников.
10. **Export CSV…** пишет таблицу и `.calculations.json` с исходными сериями,
    соответствием строк, формулами, единицами и статусами. Сохраните документ
    и откройте заново: серии и таблицы восстанавливаются независимо.
11. Измените порядок Ag-серии: старая таблица помечается устаревшей, пары строк
    сохраняются до явного **Update alignment** после пересопоставления серии.
    Удаление исходного спектра оставляет недоступную ячейку. Undo восстанавливает
    доступность; обычный экспорт устаревшего результата заблокирован.

Полные серии включают 42, 13 и 13 шагов для каждой линии в порядке VAMAS.
Для полноценной приёмки сначала сравните ΔE и отношение площадей вручную на
нескольких строках. Площади используются в физических единицах моделей, без
RSF; результат является отношением площадей, а не концентрацией.

Файл создаётся в текущем формате 1.2. Поддерживается также чтение релизных
документов 1.0 без постобработки. Промежуточный прототип 1.1 не поддерживается,
миграции старых таблиц нет. Для свежего набора выполните:
`uv run python -m scripts.prepare_ag_hopg_native --output <fresh-dir>`.

## Что изменено в разложениях

Измеренные x/y не изменены относительно обычного импорта VAMAS. Положения,
FWHM и GL взяты из CSV без оптимизации. Для совместимости площадей с исходной
шкалой интенсивности CSV Area умножена на время накопления (число сканов здесь 1):
Sample 2 — ×0,5; New HOPG Ag — ×4; New HOPG C — ×3. Коэффициенты записаны
для каждого спектра в разделе mapping файла provenance.json. Это перевод шкалы, без RSF.

Фоны Shirley оценены заново. Исходная форма CasaXPS не сохранена в CSV;
текущий pseudo-Voigt даёт приближённое наложение. Привязка промежуточных CSV
к блокам основана на порядке измерений и рецептах ноутбука; доступные DAT
служат независимыми контрольными точками. Подробности в provenance.json.
